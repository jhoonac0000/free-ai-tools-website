Learn: how to use this well

  1. Order matters. Use the Up/Down buttons so the merged file reads like one document: application form first, then ID, then certificates, or chapter 1 before chapter 2.
  2. Name files before you merge. You merge once, but you re-open the file for months. “NIC-2026.pdf” inside “Application-Ahmed.pdf” beats “scan(7).pdf”.
  3. Merge at the end, not the start. Keep the separate originals. If one page needs replacing later, you fix one small file and merge again in seconds.
  4. Check the page count. The tool reports the total pages after merging — compare it with the sum of your files before you submit anything.

Pro tips

  • Many portals accept only ONE uploaded file for all supporting documents — merging is the difference between a complete and an incomplete application.
  • After merging, run the PDF Compressor if the combined file passes the portal's MB limit.
  • Password-protected PDFs cannot be merged until the password is removed by their owner.

Frequently asked questions

Are my PDFs uploaded to a server?

No. The files are read and combined inside your browser. Nothing leaves your device and nothing is stored.

How many PDFs can I merge?

As many as your device can hold in memory. In practice, dozens of normal documents merge without trouble; very large scanned books may be slow on older phones.

Can I change the order?

Yes — every added file has Up and Down buttons. The merge follows the list exactly.

Why did one file fail?

It is most likely damaged or password-protected. Open it in a PDF reader to check, remove the password if it is yours, and add it again.
