PDF Compressor — Reduce File Size

Shrink a PDF so it fits a portal's upload limit. Your file never leaves your device — everything happens in your browser, nothing is uploaded to any server. Be aware: this tool re-renders pages as high-quality images, so text is no longer selectable afterwards — best for scanned and image-heavy PDFs.

Learn: how to use this well

  1. Scanned PDFs compress best. A 20 MB scan is mostly oversized images — that is where the big savings are. A typed, text-only PDF is already efficient and may not shrink at all; the tool tells you honestly if so.
  2. Start with Balanced. It keeps pages clearly readable for applications and statements. Use Strongest only when a hard upload limit forces it.
  3. Read the result before you submit. Open the compressed file and check the smallest text — an ID number or a grade must still be readable by a human.
  4. Keep the original. Compression is one-way. Archive the full-quality file and submit the compressed copy.

Pro tips

  • Over a portal limit by a little? Split instead: compress only the scanned pages' document, keep typed documents original, then merge.
  • Bank statements for visas: Balanced keeps stamps and signatures believable; Strongest can make them look tampered with.
  • If the result is bigger than the original (it happens with text PDFs), the tool says so — keep your original.

Frequently asked questions

Is my PDF uploaded anywhere?

No. Compression runs in your browser on your device. Nothing is uploaded or stored.

Why did my text stop being selectable?

To shrink a PDF in the browser, pages are re-rendered as images. The document looks the same and prints the same, but the text becomes part of the picture. Do not compress a PDF you still need to copy text from — keep the original for that.

Why did my file get bigger?

Text-based PDFs are already stored very efficiently. Re-rendering them as images can make them larger. The tool detects this and tells you to keep your original instead.

Will officials accept a compressed PDF?

For normal applications, yes — as long as every word and number stays readable. Always open the result and check the finest print before submitting.
