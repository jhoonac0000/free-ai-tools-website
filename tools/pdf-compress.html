PDF Compressor — Reduce File Size

Shrink a PDF so it fits a portal's upload limit. Your file never leaves your device — everything happens in your browser, nothing is uploaded to any server. The default Smart mode keeps your text fully selectable and searchable; Strong mode is there when a scan must get as small as possible and selectable text does not matter.

Smart mode rebuilds the file without touching the pages — text stays copyable and searchable, metadata is stripped and oversized embedded photos are shrunk; how much you save depends on how the file was made. Strong mode re-renders every page as a picture: far smaller for scans, but the text becomes part of the image and can no longer be selected or searched.

Learn: how to use this well

  1. Scanned PDFs compress best. A 20 MB scan is mostly oversized images — that is where the big savings are. A typed, text-only PDF is already efficient and may not shrink at all; the tool tells you honestly if so.
  2. Start with Smart. It is the default for a reason: your text stays selectable, and for most real files that is worth more than the last few KB. Switch to Strong only for scans and photo-heavy files where a hard upload limit forces it.
  3. Read the result before you submit. Open the compressed file and check the smallest text — an ID number or a grade must still be readable by a human.
  4. Keep the original. Compression is one-way. Archive the full-quality file and submit the compressed copy.

Pro tips

  • Over a portal limit by a little? Split instead: compress only the scanned pages' document, keep typed documents original, then merge.
  • Bank statements for visas: if you must use Strong mode, Light or Balanced keeps stamps and signatures believable; Strongest can make them look tampered with.
  • If the result is bigger than the original (it happens with text PDFs), the tool says so — keep your original.

Frequently asked questions

Is my PDF uploaded anywhere?

No. Compression runs in your browser on your device. Nothing is uploaded or stored.

Will my text stay selectable?

With Smart mode (the default), yes — completely. Smart mode rebuilds the file without re-rendering a single page, so every word stays copyable and searchable. Only Strong mode gives up selectable text: it re-renders pages as pictures to squeeze scans down as far as possible.

Why did my file get bigger?

Smart mode can only remove waste — metadata, file-structure overhead and oversized embedded photos. A tightly made text PDF may have almost none of that, so there is honestly nothing to save without turning pages into pictures (Strong mode). When that happens the tool tells you plainly and you keep your original.

Will officials accept a compressed PDF?

For normal applications, yes — as long as every word and number stays readable. Always open the result and check the finest print before submitting.
