Learn: how to use this well

  1. Send only what was asked for. A portal that asks for your degree does not need your whole 40-page file. Extract that one page — smaller upload, faster approval, less of your private data travelling.
  2. Split before you compress or email. A scanned book that is too big to send becomes five small chapter files. Split first, then run the PDF Compressor on the part that is still too large.
  3. Keep the original untouched. Splitting never changes your source file. Work on the extracted copy; if you pick the wrong pages, extract again in seconds.
  4. Name the parts like a filing clerk. “Statement-Jan-2026.pdf” and “Degree-page.pdf” will still make sense in six months; “split-1.pdf” will not.

Pro tips

  • Bank and salary statements: extract only the months a visa or loan officer asked for — the rest is your private business.
  • Books and manuals: one chapter per file makes reading on a phone far easier than one 300-page PDF.
  • Wrong order in the result? Ranges are extracted in the order you type them, so type 8-10, 1-3 if you want those pages first.

Frequently asked questions

Is my PDF uploaded to a server?

No. The file is read and split inside your browser. Nothing leaves your device and nothing is stored.

Can I extract pages that are not next to each other?

Yes. Type ranges and single pages together, like 1-3, 5, 8-10 — the extracted PDF keeps exactly that order.

Can I split every page into its own PDF?

Yes — use the second button. You get one small download button per page, so you can save only the pages you actually need.

Is there a page or file limit?

No fixed limit and no sign-up. The only limit is your device's memory — very large scanned books may be slow on older phones.

Why did my file fail?

It is most likely damaged or password-protected. Open it in a PDF reader to check, remove the password if it is yours, and try again.
